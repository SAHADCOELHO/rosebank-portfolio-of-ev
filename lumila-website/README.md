## Project overview
LUMILA is a fictional website concept created for this assignment. It is not a real shop. The site is a simple example of a small online fashion and lifestyle business idea in Angola.

## Pages
- `index.html` — home page
- `about.html` — about the concept, mission and vision
- `products.html` — sample products, sample prices and product search
- `enquiry.html` — product enquiry form with client-side checks
- `contact.html` — contact form and two map embeds for example areas in Luanda

## Folder structure
- `css/style.css` — external CSS stylesheet
- `js/script.js` — JavaScript interactions
- `images/` — project image assets

## Part 2 — CSS and responsive design
I added an external stylesheet and linked it to all five pages. The stylesheet includes colours, typography, navigation, cards, forms, layout, hover/focus styles and media queries.

Breakpoints used:
- Tablet: 800px and below
- Mobile: 520px and below

The layout changes to fewer columns on smaller screens. Images use a maximum width of 100% so they can fit the screen.

**Evidence:** My test screenshots are in the `evidence` folder in the root of this repository.

## Part 3 — JavaScript and SEO
JavaScript features:

SEO and accessibility:

## Important limitations
- The forms are demonstrations only. They do not send an email or save user information.
- Product names and prices are examples, not real stock or current offers.
- LUMILA and the shop locations are fictional. The map embeds show general areas in Luanda, not real branches.
- Google Maps and external image links require an internet connection.
- The website is hosted on GitHub Pages (see the links below).
- Screenshots of my tests are in the `evidence` folder.
